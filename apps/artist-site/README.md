# Artist Site

Первый прототип сайта художника: публичное портфолио, форма заявки на заказ и черновик защищенного административного блока.

## Запуск

```bash
npm start --prefix apps/artist-site
```

По умолчанию сайт доступен на `http://localhost:4173`. Порт можно изменить через переменную окружения `PORT`.

## Проверка

```bash
npm run check --prefix apps/artist-site
```

## Важно для будущего деплоя

- Пароль `change-me-before-deploy` в `assets/app.js` используется только для клиентского прототипа. Перед production-деплоем его нужно заменить серверной авторизацией.
- Файл `data/artworks.json` фиксирует контракт карточки работы: `id`, `title`, `category`, `year`, `description`, `image`, `published`.
- Директория будущих пользовательских загрузок должна быть вынесена в постоянное хранилище и сохраняться между релизами.
